Hayba
ABOUT

An AI-agent toolkit for Unreal Engine.

What is Hayba?

Hayba is an open-source (MIT) toolkit that lets an AI agent work inside a live Unreal Engine editor. It works through one Model Context Protocol connection: a Node/TypeScript MCP server talks to a C++ editor plugin, and the agent places actors, builds PCG graphs, authors materials, Blueprints and UMG widgets, and checks its own work. Each destructive step waits for your approval.

The repository also holds early research libraries for worldbuilding: linguistics, planet plausibility checks and rule-based architecture styles.

Why now?

AI agents can now call tools through the Model Context Protocol. Hayba gives an agent 400+ Unreal Engine editor tools, found on demand, and Plan Mode keeps destructive steps waiting until you approve them.

Who builds it

Currently one developer (Badr) plus the community on GitHub. Built on the Model Context Protocol and Unreal Engine 5.8.

License

Hayba's source code is MIT-licensed. A hosted assistant, Hayba Pro, is coming. The open-source toolkit stays MIT and runs with your own model.
