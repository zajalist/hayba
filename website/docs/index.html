Hayba documentation

Hayba lets an AI agent work inside a running Unreal Engine editor. It has two parts: an MCP server written in TypeScript and a C++ editor plugin. Your agent places actors, builds Blueprints, materials, UMG widgets and PCG graphs, runs Play-In-Editor tests, and reads the editor back to check its own work.

Hayba runs on Windows only and supports Unreal Engine 5.7+. There is no installer yet: you build it from source. These pages describe the current source on the main branch. The latest completed release is v0.3.0. Where a page describes the 0.4.0 release candidate that is already in the source, it says so.

Quick start

The short version. Getting started has every step in full.

  1. Install Node.js 22.5 or newer, Git, and Visual Studio with the C++ toolchain your engine version needs.
  2. Clone the repo and build the MCP server.
  3. Link unreal/HaybaMCPToolkit into your project's Plugins folder and build the project.
  4. Register the server with your MCP client, open the project, and ask the agent to check the connection.
Terminal
git clone https://github.com/zajalist/hayba.git
cd hayba
npm install
npm --prefix mcp-tools/hayba-mcp run build

Start in a scratch project. Hayba can change and save editor state, and some changes cannot be undone.
