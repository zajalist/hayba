Hayba

An AI-agent toolkit for Unreal Engine: a Node/TypeScript MCP server plus a C++ editor plugin. These notes cover the current source on main; the latest tagged release is v0.1.0 (August 2026).

Install

Hayba builds from source on Windows. You need UE 5.7 or 5.8, Visual Studio with the C++ toolchain your Unreal Engine version requires, and Node.js 22.5 or newer.

1. Clone and build the MCP server: git clone https://github.com/zajalist/hayba.git, then in the repo run npm install and npm --prefix mcp-tools/hayba-mcp run build.

2. Create <YourProject>\Plugins if it doesn't exist, then link the plugin into it from an administrator prompt (or with Windows Developer Mode on): mklink /D "<YourProject>\Plugins\HaybaMCPToolkit" "<repo>\unreal\HaybaMCPToolkit", then regenerate Visual Studio project files and compile. The link lets the plugin find the MCP server you just built. If you copy the plugin instead, set SidecarEntryPath under [HaybaMCPToolkit] in your project's Saved/Config/WindowsEditor/EditorPerProjectUserSettings.ini to the full path of mcp-tools/hayba-mcp/dist/index.js.

3. Register the server with your agent host. For Claude Code: claude mcp add hayba-toolkit -- node /path/to/hayba/mcp-tools/hayba-mcp/dist/index.js

First run

On first launch the Hayba MCP Toolkit tab opens by itself (later: Tools > Hayba MCP Toolkit, or the console command Hayba.MCP.Open). Your MCP host drives the agent. To chat inside the editor instead, set a provider (and key, for cloud models) under Settings > AI / LLM Backend. Plan Mode is on by default: approve plans in the Plan tab.

Unreal toolkit (MCP)

Hayba speaks the Model Context Protocol over stdio. It works with Claude Code, Claude Desktop and other MCP clients. The agent places actors, builds PCG graphs, and authors materials, Blueprints and UMG widgets inside a live Unreal Engine 5.7+ editor.

The current source on main has 400+ editor tools across 30+ editor domains. The server starts with 7 tools; the agent searches the catalogue and calls the rest on demand.

Early research

The repository also holds early research libraries for worldbuilding: a constructed-language toolkit (packages/linguistics), planet plausibility checks (packages/planet-physics) and rule-based architecture styles (packages/architecture). They are early-stage and separate from the Unreal toolkit.
