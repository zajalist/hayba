Hayba

An AI-agent toolkit for Unreal Engine: a Node/TypeScript MCP server plus a C++ editor plugin. These notes cover the current source on main; the latest tagged release is v0.1.0 (August 2026).

Install

Hayba builds from source on Windows. You need Unreal Engine 5.7+, Visual Studio with the C++ toolchain your Unreal Engine version requires, and Node.js 22.5 or newer.

  1. Build the MCP server

    Clone the repo, install its dependencies and build the server:

    Terminal
    git clone https://github.com/zajalist/hayba.git
cd hayba
npm install
npm --prefix mcp-tools/hayba-mcp run build

  2. Add the plugin to your project

    Create <YourProject>\Plugins if it doesn't exist, then link the plugin into it from an administrator Command Prompt (or with Windows Developer Mode on). Replace <YourProject> and <repo> with your project folder and your Hayba clone:

    Command Prompt
    mklink /D "<YourProject>\Plugins\HaybaMCPToolkit" "<repo>\unreal\HaybaMCPToolkit"

    Then regenerate Visual Studio project files and compile. The link lets the plugin find the MCP server you just built.

    If you copy the plugin instead of linking it, point it at the server in <YourProject>/Saved/Config/WindowsEditor/EditorPerProjectUserSettings.ini, using the full path to your clone:

    EditorPerProjectUserSettings.ini
    [HaybaMCPToolkit]
SidecarEntryPath=<repo>\mcp-tools\hayba-mcp\dist\index.js

  3. Register the server with your agent host

    For Claude Code:

    Terminal
    claude mcp add hayba-toolkit -- node /path/to/hayba/mcp-tools/hayba-mcp/dist/index.js

The repo README has the same steps and the Claude Desktop config.

First run

On first launch the Hayba MCP Toolkit tab opens by itself (later: Tools > Hayba MCP Toolkit, or the console command Hayba.MCP.Open). Your MCP host drives the agent. To chat inside the editor instead, set a provider (and key, for cloud models) under Settings > AI / LLM Backend. Plan Mode is on by default: approve plans in the Plan tab.

Unreal toolkit (MCP)

Hayba speaks the Model Context Protocol over stdio. It works with Claude Code, Claude Desktop and other MCP clients. The agent places actors, builds PCG graphs, and authors materials, Blueprints and UMG widgets inside a live Unreal Engine 5.7+ editor.

The current source on main has 400+ editor tools across 30+ editor domains. The server starts with 7 tools; the agent searches the catalogue and calls the rest on demand.
