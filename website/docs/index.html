Hayba v0.1.0

An AI-agent toolkit for Unreal Engine: a Node/TypeScript MCP server plus a C++ editor plugin. v0.1.0 is early access; these notes cover it.

Install

Hayba builds from source on Windows, with Unreal Engine 5.8, Visual Studio 2022 and Node.js 22.5 or newer.

1. Clone and build the MCP server: git clone https://github.com/zajalist/hayba.git, then in the repo run npm install and npm --prefix mcp-tools/hayba-mcp run build.

2. Copy unreal/HaybaMCPToolkit into your project's Plugins/ folder, regenerate Visual Studio project files and compile.

3. Register the server with your agent host. For Claude Code: claude mcp add hayba-toolkit -- node /path/to/hayba/mcp-tools/hayba-mcp/dist/index.js

WIP Full install guide is being written. In the meantime, see the repo README for the canonical setup.

First run

Open your project in Unreal Engine; the Hayba MCP Toolkit panel appears in the toolbar. Pick Integrated (your MCP host drives the agent) or API Key (chat with the editor directly using your own key). Plan Mode is on by default, so destructive steps wait until you click Approve in the Plan tab.

Unreal toolkit (MCP)

Hayba speaks the Model Context Protocol over stdio. It works with Claude Code, Claude Desktop and other MCP clients. The agent places actors, builds PCG graphs, and authors materials, Blueprints and UMG widgets inside a live Unreal Engine 5.8 editor.

400+ editor tools across 30+ editor domains. The server starts with 7 tools; the agent searches the catalogue and calls the rest on demand. The Capabilities panel turns tools off per tool or per domain.

Early research

The repository also holds early research libraries for worldbuilding: a constructed-language toolkit (packages/linguistics), planet plausibility checks (packages/planet-physics) and rule-based architecture styles (packages/architecture). They are early-stage and separate from the Unreal toolkit.
