Built not to crash
your editor.

An agent can send thousands of editor commands in a session. When one of them goes wrong, Hayba refuses the work instead of taking the editor down with it.

Faults stay contained
Hayba contains native faults in its handlers, then refuses unsafe work until you restart the editor.
Read-only files are refused
A save to a read-only file comes back as a refusal, not a crash.
Play-In-Editor is guarded
Hayba guards Play-In-Editor sessions and assets that are still under construction.
One agent per asset
Multi-agent editing uses leases, so two agents never edit the same asset at once.
You approve destructive steps
With Plan Mode on (the default), destructive steps wait for your approval. Most edits land on Unreal's undo stack, so Ctrl+Z works.

Get Hayba, free.

Hayba builds from source. You need Unreal Engine 5.7+, Visual Studio with the C++ toolchain your engine version requires, and Node.js 22.5 or newer.

One-line installer coming in v0.5.

PowerShell
# Build the MCP server
git clone https://github.com/zajalist/hayba.git
cd hayba
npm install
npm --prefix mcp-tools/hayba-mcp run build

# Link the plugin into your project (run as administrator, or turn on Developer Mode)
cmd /c mklink /D "<YourProject>\Plugins\HaybaMCPToolkit" "$PWD\unreal\HaybaMCPToolkit"

# Register the server with Claude Code
claude mcp add hayba-toolkit -- node "$PWD\mcp-tools\hayba-mcp\dist\index.js"

Then regenerate your project files and compile. The install guide covers copying the plugin instead of linking it, and Claude Desktop.

Common questions.

Short answers about cost, models, requirements and licensing.

Is Hayba free?

Yes. The toolkit is free and MIT-licensed, and runs with your own MCP client or model. Hayba Pro, at $15 a month or $150 a year, adds a hosted brain and the bulk Blueprint builder; join the waitlist for early access.

What's in Pro?

The hosted brain, which plans multi-step work with no API key needed; the bulk Blueprint builder, which builds whole Blueprints and widgets from a spec; and every skill pack. Pro is in early access soon.

Was this game really made with AI?

Its gameplay Blueprints and UI widgets were built by an AI agent through Hayba. Some materials were scripted through Hayba's Python bridge. The art, levels and other assets were not.

Do I need an LLM API key?

Not for Hayba itself. Connect your MCP client, such as Claude Code or Claude Desktop, and it uses the model it already has. The optional in-editor chat uses your own API key for cloud models, or a local model (Ollama, LM Studio) with no key.

Will this run on my machine?

Hayba supports Unreal Engine 5.7+ on Windows; macOS and Linux are not supported yet. The MCP server is Node/TypeScript (Node.js 22.5 or newer) and the editor plugin is C++; building it needs Visual Studio with the C++ toolchain your Unreal Engine version requires. There is no packaged installer yet: you build from source.

Can I use Hayba commercially?

Hayba's source code is MIT-licensed, which permits commercial use under the terms of the MIT license. Unreal Engine's own license still applies to your project.
