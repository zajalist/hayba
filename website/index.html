Toolkit · Unreal Engine 5.7+

An MCP your LLM
can author with.

Hayba is an open-source toolkit that lets an AI agent work inside a live Unreal Engine editor. A Node/TypeScript MCP server talks to a C++ editor plugin, so the agent can place actors, build PCG graphs, author materials, Blueprints and UMG widgets, and check its own work.

The current source on main has 400+ editor tools across 30+ editor domains. The server starts with 7 tools; your agent searches for the rest and calls them on demand.

Workflow

Destructive steps wait
for your approval.

Drive Hayba from your MCP host, such as Claude Code or Claude Desktop, or chat with the editor directly from the Hayba panel, using your own API key for cloud models, or a local model (Ollama, LM Studio) with no key.

With Plan Mode on (the default), destructive steps wait until you approve the plan. Most editor edits land on Unreal's normal undo stack, so Ctrl+Z works — not during Play-In-Editor, and not for asset deletes, saves to disk or arbitrary Python.

Open source

MIT-licensed.
Forkable. Inspectable.

The MCP server and the Unreal editor plugin are MIT-licensed and on GitHub. The toolkit runs locally with your own MCP client or your own API key; no Hayba account is needed.

The latest tagged release is v0.1.0 (early access), and Hayba runs on Windows. Install from source: clone the repo, build the MCP server, link the plugin into your project's Plugins folder and compile.

FAQ

Common questions.

Short answers about cost, models, requirements and licensing.

Is Hayba free?

Yes, the toolkit is free to use. A hosted assistant, Hayba Pro, is coming. The open-source toolkit is MIT-licensed and runs with your own model.

Do I need an LLM API key?

Not for Hayba itself. Connect your MCP client, such as Claude Code or Claude Desktop, and it uses the model it already has. The optional in-editor chat uses your own API key for cloud models, or a local model (Ollama, LM Studio) with no key.

Will this run on my machine?

Hayba supports Unreal Engine 5.7+ on Windows; macOS and Linux are not supported yet. The MCP server is Node/TypeScript (Node.js 22.5 or newer) and the editor plugin is C++; building it needs Visual Studio with the C++ toolchain your Unreal Engine version requires. There is no packaged installer yet: you build from source.

Can I use Hayba commercially?

Hayba's source code is MIT-licensed, which permits commercial use under the terms of the MIT license. Unreal Engine's own license still applies to your project.
