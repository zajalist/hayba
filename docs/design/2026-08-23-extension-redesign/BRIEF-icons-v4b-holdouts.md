# Icon redo — v4b holdouts (undo, save, code, 3 state marks)

Same pipeline (image_gen → palette-normalize flat `#DED4C3`/`#C47A28`,
transparent, 512px). Same style contract: filled, chunky, rounded,
folk-geometric, two-tone, bold at 28px. TWO candidates each
(`<name>-a.png`, `<name>-b.png`).

Rejected so far, never redraw: undo = curled arrow, U-turn arrow, footprints.
save = lidded pot, strongbox chest, tied sack. python = any serpent/snake/coil.
state marks = triangle, clock-wedge, plain dot, thin pennant, thin spoon-!,
thin hourglass, sun-at-horizon, thin 4-point spark, open-gap circle.

1. **undo** — (a) a chunky counterclockwise arrow wrapping most of the way
   around a solid center dot (turning back around a moment in time), arrow
   cream, dot ochre; (b) a fat rounded eraser at an angle lifting away a
   short ochre mark it has just removed.

2. **save** — the user asked for MORE RECOGNISABLE, so convention wins over
   novelty: (a) the classic floppy disk, folk-chunked — rounded corners, big
   label notch, shutter as one ochre block, zero small details; (b) a bold
   downward arrow docking into an open box/tray, arrow ochre. Instantly
   readable as "save" is the whole requirement.

3. **python** (the file name stays `python.png`, but the glyph is now a
   CODE mark, not an animal) — (a) chunky code brackets with a slash:
   `</>` as three fat rounded forms, slash ochre; (b) a rounded terminal
   window: thick frame, one fat ochre prompt chevron inside, one cream
   input bar. No text, no tiny glyphs.

4. **state marks** — rejected for lacking silhouette. These must be SOLID,
   FAT, unmistakable shapes that hold at 14px. One strong mass each, minimal
   negative space:
   - **state-attention** — (a) a solid rounded flame, ochre; (b) a solid
     fused exclamation: fat tapered stroke merging into its dot, one shape,
     ochre.
   - **state-pending** — (a) a solid fat hourglass silhouette (filled, both
     bulbs solid, waist thick), ochre; (b) a solid half-disc moon with a
     rounded profile, ochre.
   - **state-unsaved** — (a) a fat four-lobe spark: rounded petals, thick
     center, reads as a solid clover-star (echoes the logo spark but with
     real mass), ochre; (b) a solid ink/water drop, ochre.
