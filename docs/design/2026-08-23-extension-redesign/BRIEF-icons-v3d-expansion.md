# Icon expansion — v3d: the comprehensive set

Same pipeline as v3b/v3c (image_gen AI generation → System.Drawing palette
normalization to flat `#DED4C3` / `#C47A28`, transparent alpha, 512px). Same
style contract: filled silhouette, no outlines/gradients/shadows, chunky
rounded folk-geometric in the Hayba logo's language
(`unreal/HaybaMCPToolkit/Resources/HaybaLogo.svg`), two-tone (cream dominant,
ONE ochre accent), legible at 28px and 16px. Lead each prompt with the
METAPHOR, then the style. ONE image per icon (no candidates this round).

These extend the existing curated set (docs/design/2026-08-23-extension-redesign/
icons-final/ — study 3-4 of them first for mass and treatment so the new
icons match). Do not regenerate anything that exists.

## Action icons (12)

1.  `run`      — chunky rounded play wedge, ochre.
2.  `approve`  — bold rounded check standing alone on a small base, ochre check.
3.  `reject`   — bold rounded cross, cream with ochre tips or plain cream.
4.  `save`     — a rounded vessel/chest with its lid closing, ochre lid.
5.  `search`   — folk magnifier: round lens + stubby handle, ochre handle.
6.  `refresh`  — one chunky circular arrow, ochre head.
7.  `add`      — bold rounded plus, cream on nothing, ochre center optional.
8.  `remove`   — bold rounded minus.
9.  `close`    — compact rounded X, smaller mass than reject.
10. `expand`   — two rounded corner brackets pulling apart, ochre one corner.
11. `capture`  — folk camera: rounded body + lens circle, ochre lens.
12. `connect`  — two rounded link halves meeting, joint ochre.

## Domain icons (8) — Unreal-world subjects

13. `terrain`   — layered hill strata seen in cross-section, one ochre stratum
                  (must differ clearly from the existing `world` hill: this is
                  CUT ground, not a horizon).
14. `foliage`   — a chunky rounded tree/shrub cluster, ochre trunk or one bush.
15. `pcg-graph` — three rounded nodes joined by thick links, one node ochre.
16. `material`  — a folk paint-dab / swatch drop on a rounded tile, dab ochre.
17. `blueprint` — a rounded scroll/plan sheet with one thick routed line, line ochre.
18. `python`    — a rounded coiled form (a coil, NOT a literal snake with eyes),
                  ochre head-end.
19. `build`     — a folk hammer over a rounded block, hammer head ochre.
20. `camera-viewport` — a rounded viewport frame with corner nubs, one nub ochre.
