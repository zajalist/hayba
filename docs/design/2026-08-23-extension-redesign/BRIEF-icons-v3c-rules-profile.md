# Icon regen — v3c: rules + profile, new metaphors

Same pipeline as v3b (image_gen AI generation → System.Drawing palette
normalization to flat `#DED4C3` / `#C47A28`, transparent alpha, 512px).
Same style contract: filled silhouette, no outlines/gradients/shadows,
chunky rounded folk-geometric in the Hayba logo's language
(`unreal/HaybaMCPToolkit/Resources/HaybaLogo.svg`), two-tone, legible at
28px. Lead every prompt with the METAPHOR, then the style.

The tablet/stele direction for `rules` and the vase/crate direction for
`profile` are both REJECTED — do not revisit them.

## rules — "what must be true" (3 candidates, new metaphors)

- **rules-a — the plumb bob.** A chunky rounded plumb bob hanging from a
  short cord anchored at a top bar; bob ochre, bar+cord cream. The tool that
  tells you what is true. (This is also the product's own constraint engine
  name, PLUMB — the brand tie-in is intended.)
- **rules-b — the balance scale.** A folk-style two-pan balance, level;
  chunky central post and rounded pans; one pan or the beam ochre.
- **rules-c — the level.** A rounded spirit-level block with its centered
  bubble window; bubble ochre, dead-center.

Must NOT read as: tombstone, bell, thimble, document.

## profile — "what an asset IS" (3 candidates, new metaphors)

- **profile-a — the tag.** A rounded object (simple pebble/block) with a
  chunky ochre identity tag attached by a short loop — the asset and its
  known identity.
- **profile-b — the calipers.** A rounded object held between the two jaws
  of a chunky folk caliper; caliper ochre, object cream. Measured =
  understood.
- **profile-c — the object and its blueprint.** A rounded object sitting
  above its simplified ochre footprint/outline-shadow below it — the thing
  and what the system knows of it.

Must NOT read as: vase, jar, person, food.
