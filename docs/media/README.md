# Public demo media

The Chat and World images in this directory are direct captures from a scratch Unreal Engine 5.8 project with synthetic content. The World capture shows a loaded level with 1,024 synthetic static-mesh actors and 130,048 sampled points. It is an interface demonstration, not a benchmark or a claim about unloaded World Partition cells.

Public demo media should come from synthetic scratch projects. Check every frame, filename, caption, and embedded metadata before publishing. A capture from a game project must not be copied into this directory merely because the Hayba interface is visible in it.
