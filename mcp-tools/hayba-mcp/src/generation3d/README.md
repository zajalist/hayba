# Media generation HTTP contract

Mount `registerGeneration3DRoutes(app)` from `routes.ts` before any app-wide JSON parser. These are local HTTP routes, not MCP tools. Every route requires a loopback peer and Host and, when present, a loopback browser Origin. POST requires `application/json`; the router parses at most 16 KiB. Responses disable caching.

The canonical base path is `/chat/generation`; `/chat/3d` remains a compatibility alias to the same guarded router. `GET /chat/generation/providers` returns `{providers:[...]}` with supported models, output kind, modes, styles, progress availability and Meshy's separate refine charge. Provider IDs and output kinds are `meshy|tripo|aholo` → `model`, `fal` → `video`, and `worldlabs` → `splat`.

`POST /chat/3d/connection` accepts `{provider,api_key}`. Success returns `{provider,status:"verified",verified:true,message}` after a read-only authenticated request. It does not persist credentials. Probes are Meshy text-to-3D list (`page_size=1`), Tripo account balance, and Aholo task list (`page=1&pagesize=1`). Account contents and balances are discarded.

World Labs uses the read-only `GET /marble/v1/credits` probe, discarding the balance. fal returns `{provider:"fal",status:"configured",verified:false,message}` without a provider request: the UI must say the key is saved but unverified. No paid generation is used to test credentials. A successful fal generation verifies usable access only for that request; this adapter does not persist connection state.

`POST /chat/3d/tasks` accepts `{provider,api_key,prompt?,model?,image_url?,style?,preview_task_id?}`. Unknown fields are rejected. Supply a prompt, image URL or Meshy preview ID. Tripo accepts either prompt or image, not both. Aholo accepts image alone or text with an optional reference image. Meshy accepts text only; supplying a preview ID explicitly starts a separate refine task. Style is supported only for Aholo text generation. Defaults and supported values are in provider metadata.

fal and World Labs currently accept text prompts only, with an optional allowlisted model. They reject image/style/refine fields. fal uses the fixed `fal-ai/wan/v2.7/text-to-video` model, explicitly submitting five seconds at 1080p. World Labs defaults to `marble-1.1`, with `marble-1.1-plus` and `marble-1.0-draft` also allowed. No arbitrary provider URL or model endpoint is accepted.

`POST /chat/3d/tasks/status` accepts `{provider,api_key,task_id,phase?}`. Meshy phase may be `preview` or `refine`; pass the creation response's phase through subsequent polls.

Creation and status return `{provider,task_id,kind,status,progress,phase?,result_url?,model_url?,thumbnail_url?,error?}`. IDs are strings, including Aholo numeric IDs. Status is `queued|running|succeeded|failed|cancelled`. Progress is 0–100 or `null` when unavailable; Aholo, fal and World Labs have no numeric running progress in this adapter. Creation reports accepted/queued, never completion. `result_url` is the GLB/model, video or SPZ download; model tasks also retain `model_url` for compatibility. Result links are returned only after success; no download or import runs here. A successful task without a safe result URL retains `succeeded` and includes an explanation in `error`.

Request failures return `{error:{code,message}}` with HTTP 400/413/415 for input issues, 403 for locality violations, 401 for rejected credentials/permissions, 402 for insufficient credits, 429 for rate limits, 502 for upstream errors, or 504 for timeout. Messages are static and never copy upstream error bodies. A timeout/network failure after submitting may leave a billed provider task; clients must not automatically retry creation.

Outbound requests use fixed HTTPS origins, reject redirects, time out after 15 seconds and read at most 256 KiB per response. Keys travel only in provider authentication headers and incoming local JSON, never URLs or responses. Image/result links require public HTTPS host syntax and no credentials, nonstandard ports or literal private addresses. IPv6 literal links are conservatively refused. This service never resolves or fetches asset URLs. DNS resolution and remote asset availability are not verified.

## Official request mappings

* Meshy: `https://api.meshy.ai/openapi/v2/text-to-3d`, Bearer authorization. Preview sends `mode,prompt,ai_model,target_formats:["glb"]`; refine sends `mode:"refine",preview_task_id,texture_prompt?,ai_model?`. GET `/{task_id}` reads uppercase lifecycle states, `model_urls.glb` and `thumbnail_url`. [Text to 3D API](https://docs.meshy.ai/en/api/text-to-3d).
* Tripo: `https://openapi.tripo3d.com/v3/generation/text-to-model` sends `prompt,model`; image-to-model sends `input:<image URL>,model`. Bearer authorization. GET `/v3/tasks/{task_id}` reads `data.status`, `data.progress`, `data.output.model_url` and `rendered_image_url`; legacy banned/expired states are terminal failures. [Quick start](https://developers.tripo3d.com/en/docs/quick-start), [image generation](https://developers.tripo3d.com/en/docs/generation-image-to-model/standard), [task query](https://developers.tripo3d.com/en/docs/task-query), [account probe](https://developers.tripo3d.com/en/docs/account).
* Aholo: `https://api.aholo3d.cn/lux3d/v1/generate/text-to-3d/task/create` sends `prompt,style?,img?,version,outputFormat:["glb"]`; image-only uses `img-to-3d/task/create` with `img,version,outputFormat`. Authorization is the raw key, without Bearer. Creation reads `c:"0",d:<ID>`; GET `/lux3d/v1/generate/task/get?taskid=<ID>` reads `d.status` (0 queued, 1 running, 3 succeeded, 4 failed, 6 cancelled) and `d.outputs[].content`. G1 can return ZIP then GLB; G1-Turbo returns the requested format. [API reference](https://labs.aholo.ai/api-docs/api-reference), [machine-readable OpenAPI](https://labs.aholo.ai/api-docs/openapi.json), [Lux3D skill](https://labs.aholo.ai/api-docs/skills/lux3d).

Checked against official documentation on 2026-11-12. Aholo's prose skill has older data-URL-only language; its linked OpenAPI explicitly documents public image URLs and optional/default style, and is the request schema used here. Only the documented China gateway is supported; region-specific credentials may need a future fixed region selector. Generated links expire (Tripo documents five minutes; Aholo two hours).

* fal: POST `https://queue.fal.run/fal-ai/wan/v2.7/text-to-video` with `Authorization: Key ...` submits `prompt,duration:5,resolution:"1080p"`. Poll `GET /fal-ai/wan/requests/{request_id}/status`; on `COMPLETED`, get `/fal-ai/wan/requests/{request_id}` and read `video.url`. Queue URLs returned by the provider are ignored. Terminal result HTTP 422/499 maps to failed/cancelled without copying its error body. [Wan model schema](https://fal.ai/models/fal-ai/wan/v2.7/text-to-video/api), [queue status](https://fal.ai/docs/api-reference/inference-api/queue/status), [queue result](https://fal.ai/docs/api-reference/inference-api/queue/result).
* World Labs: POST `https://api.worldlabs.ai/marble/v1/worlds:generate` with `WLT-Api-Key` sends `model,display_name,world_prompt:{type:"text",text_prompt}`. Poll `/marble/v1/operations/{operation_id}`; `done` and `error` determine state. Successful `response.assets.splats.spz_urls` supplies full-resolution SPZ, falling back to 500k/100k when necessary. No additional export is submitted. [Quickstart](https://docs.worldlabs.ai/api), [models](https://docs.worldlabs.ai/api/models), [operation contract](https://docs.worldlabs.ai/api/reference/operations/get), [read-only credits](https://docs.worldlabs.ai/api/reference/credits/get).

These are download links, not built-in video playback or splat rendering. World Labs exports carry scale metadata that a future importer must honor; no importer is claimed here. Provider result links can expire. fal queue results have short retention, so download successful outputs promptly. Provider-side cancellation is not exposed by this initial media interface; closing a panel does not cancel billed work.

Tests use fake fetch transport and real local Express HTTP requests. No paid provider call or real key is used. Passing these tests verifies mapping, validation, sanitization and routing, not actual provider generation or native asset import.
