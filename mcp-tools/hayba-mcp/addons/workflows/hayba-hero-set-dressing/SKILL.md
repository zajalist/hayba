# Dress a focal area

## When to use

Use for a plaza, room, vista, encounter anchor, or other authored focal space. Determine the view and the playable clearance before adding pieces. Preserve the ownership boundary if nearby content is generated by PCG.

## Tool routing

- Read `scene_export` and capture the current camera with `editor_capture_viewport`. Search project assets through `hayba_asset_search`; verify class, scale, and path before selection.
- Place a content asset with `actor_spawn_from_asset`, then use `placement_validate` and `scene_validate_physics` to check grounding and intersections. `actor_transform` is appropriate for a small correction after the exact actor is identified. Prefer fewer purposeful pieces when repeated detail weakens the focal point.
- If the area needs a broad repeated field, hand that portion to hayba-foliage-layout or hayba-pcg-build. Keep individually authored hero actors outside regenerated ownership.
- Once placements are accepted, save the exact active map with `level_save`, inspect saved, dirty, and verified status, and re-read the placed actors with `actor_list` or `actor_inspect`. If persistence remains uncertain, mark the layout unsaved and route it to hayba-world-save-integrity.

## Evidence

Report chosen asset paths, placement counts, before/after captures from the same viewpoint, and any collisions or clearance concerns. Run `validator_run` after placement. Stop after one coherent focal pass and one correction pass unless the user asks for further exploration.
